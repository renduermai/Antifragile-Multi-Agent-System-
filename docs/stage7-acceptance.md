## 亲自验收

1. 打开灵石区。检查每日 LLM 上限 20、每轮深研上限 3、定时扫描关闭；行情为 Alpaca/IEX，搜索为 Tavily。接口旁的「测试」会消耗一次对应接口请求。
2. 打开机会猎场。到「重点行情池 · 最近成交」数 12 行，任选 NVDA 和 GLD 对照品种、美元单位、来源、成交时间。直接查看已保存的数据无需联网调用。
3. 点「手动采集」，搜索词可留空。金融行情和独立搜索分别显示结果；未启用的新闻接口也单列状态。「未变化」表示已保存同一观测。此按钮不调用 LLM。
4. 点开任一事件，核对来源链接、发布时间、采集时间、原始材料及版本。在有实际判断时可记录状态和未解决矛盾；刷新或重启后打开同一事件可查。通过关注的新原文建立关联，后续可对照两次判断。
5. 用「机会扫描与定向研究」选择资产代码并输入 NVDA，或留在「全部配置数据源」扫描全球主题。此按钮可能调用 LLM。检查每份报告中的引用、未知项、概率快照及数据限制。研究等级和总任务状态分别展示。供应商缺失、达到上限或仍有候选推迟时可显示部分完成。
6. 到案例区切换黄金、原油和英伟达档案。真实案例由用户提供。使用案例 TXT 的带时区时间标记预览各轮；锁定预测后，再用分开保存的验证 TXT 对照。可直接查看[案例 TXT、验证 TXT 和评分字段](stage5-cases.md)。

## 备份及恢复

命令在项目目录中运行。每次备份或恢复均选择新的目标目录。备份工具在各库上取得写锁并使用 SQLite Backup API 读取已提交页，随后检查完整性、外键及 SHA-256。默认数据目录为项目下的 `data`。以下示例会在项目同级的 backups 与 recovered 目录中创建新快照。

```powershell
$stamp = Get-Date -Format yyyyMMdd-HHmmss
$backupDir = Join-Path '..\backups' $stamp
$restoreDir = Join-Path '..\recovered' $stamp
.\.venv\Scripts\python.exe -m app.backup create $backupDir
.\.venv\Scripts\python.exe -m app.backup restore $restoreDir --source $backupDir
```

要查看恢复的数据，在仅用于恢复验证的 PowerShell 窗口设置数据目录，再启动独立实例。请先确认备份时调度已关闭，避免恢复副本补跑任务。

```powershell
$env:AF_DATA_DIR = (Resolve-Path $restoreDir).Path
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8766
```

打开 [恢复副本](http://127.0.0.1:8766/)，核对原事件、报告及证据编号。数据库快照包括运行配置、研究、案例、预测、验证与已有图检查点。密钥由应用单独保存在本地 `data/secrets.json`，正式启用恢复副本时在灵石区重新填写。完成后按 Ctrl+C 关闭验证实例。每个数据目录使用单个服务进程。

本次从运行中的数据库备份并启动了独立恢复副本。逐行核对首轮 12 条原始成交、7 条原始搜索结果及发布时间、1,092 条日线、3 份首轮受限报告及扫描状态，内容一致。最终 NVDA 定向扫描后，再次从正式库恢复到另一独立目录，通过应用 HTTP 接口逐项比对 3 份报告及其中 2 份已锁定快照，返回值一致。三个案例的两类 TXT 均为空，恢复副本的所有 Provider 均没有密钥。

## 扩展接口

- 新增新闻或搜索源时，在 `app/providers.py` 注册 Provider、探针及请求适配，在 `app/collection.py` 接入独立采集与预算，并在 `app/research.py` 做证据归一化。保留上游原文、URL、发布时间与采集时间。已有结构支持从新闻中明确出现的池外代码建立事件关联，缺乏标识的事件可以暂留待确认。
- 新行情或衍生品源沿用 `app/relative_value.py` 的历史口径及 `app/expectations.py`、`app/options.py` 的期权读数和复核接口。扩展时分别标识品种、报价单位、复权规则、合约和行情源。
- 研究筛选规则在 `config/research.toml`，研究图和缓存位于 `app/scanning.py`。修改推理输入或证据格式时更新 `app/hypotheses.py` 的提示版本以区分历史记录。案例预测和事后评分分别位于 `app/case_forecast.py` 和 `app/case_audit.py`。
